# PetScan 獸醫隨行
2024 行動應用創新賽作品  
[2024行動應用創新賽官網](https://maic2024.iosclub.tw)  
### 作品簡介
近年來養寵物的家庭劇增，而寵物健康也成為所要面對的問題之一。根據統計指出，將近有10%至15％的寵物患有皮膚病。而因技術進步，看獸醫的成本日趨漸增，成為不小的負擔。本團隊希望藉由 PetScan獸醫隨行，讓使用者可以不限時間地點，不只減輕寵物的負擔，也可以減少看醫生的成本。
